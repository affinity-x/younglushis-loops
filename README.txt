YOUNGLUSHIS SITE — SETUP

1. Add your own original MP3 previews into audio/.
2. Edit the tracks array near the bottom of index.html with the correct filenames, BPM, and keys.
3. Create a ZIP containing your original WAV and MIDI loops and your completed LICENSE.txt.
4. Put that ZIP next to index.html. Edit zipFile in index.html to the ZIP filename.
5. Upload the contents of this folder to a GitHub repository and enable GitHub Pages in Settings > Pages.
6. Copy your published URL into the ChatPlace After subscription button URL.

IMPORTANT: The sample tracks are placeholders. The download button is intentionally disabled until a ZIP is configured. Review your license terms before distribution. Do not include personal information in files or metadata.
